03 / Modèle commun

Un même point de départ, des APIs précises

Les wrappers graphiques partagent un modèle de données basé sur config, data et les providers de @oneteme/jquery-core. Les options natives et les capacités supplémentaires restent documentées dans l'API du wrapper concerné.
