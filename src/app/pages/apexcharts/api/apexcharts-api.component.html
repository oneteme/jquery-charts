Le même contrat, plusieurs capacités

Chaque carte utilise le composant public <chart>. Les familles, options natives, événements, synchronisations et actions exposées restent pilotés par le même contrat Angular.

Familles de graphiques prises en charge

Les cinq directives internes adaptent les séries communes vers les formats line, bar, pie, treemap et range d’ApexCharts. Un type ne peut être changé qu’à l’intérieur de sa famille de données.

WRAPPER

Chargement et absence de données

isLoading modifie le message no-data utilisé par les directives. Pour rendre l’état observable, la démonstration vide aussi les lignes ; les deux états restent distincts du graphique prêt à afficher.

isLoading
Code minimal
<chart
  type="line"
  [config]="config"
  [data]="rows"
  [isLoading]="isLoading">
</chart>

WRAPPER → APEXCHARTS NATIF

Options natives via config.options

Les options propres à ApexCharts restent accessibles sans créer un nouvel input Angular. Le wrapper fusionne ces options avec les dimensions, titres et séries construites depuis le provider.

options
jquery-coreseries · axes · donnéesLe provider décrit les données et le modèle commun.
ApexChartsstroke · markers · tooltip · zoomconfig.options est fusionné après les options communes.
Code minimal
const config: ChartProvider<string, number> = {
  series: [{ name: 'Déploiements', data: { x: field('week'), y: field('count') } }],
  options: {
    stroke: { curve: 'smooth', width: 3 },
    dataLabels: { enabled: false },
    tooltip: { shared: true },
  },
};

WRAPPER → APEXCHARTS NATIF

Option rendue prioritaire

renderedOption fournit une option ApexCharts complète après la construction commune. Les propriétés présentes dans cette option prennent la priorité sur les valeurs concurrentes du provider.

renderedOption
ChartProvider titre concurrent · toolbar=false · courbe droite orange Le provider fournit volontairement des valeurs qui doivent être écrasées.
renderedOption titre natif · courbe bleue lissée · toolbar de zoom Le rendu visible confirme la priorité de l’option ApexCharts.
Code minimal
const nativeOption = {
  chart: { type: 'line', zoom: { enabled: true } },
  xaxis: { categories: ['Jan', 'Fév', 'Mar'] },
  series: [{ name: 'Option native', data: [4, 7, 5] }],
};

<chart
  [config]="{ series: [] }"
  [data]="rows"
  [renderedOption]="nativeOption">
</chart>

WRAPPER + CORE

Synchronisation tooltip et zoom

Deux instances ApexCharts portant le même group relaient les interactions déclarées par groupSync. Ici, le survol et le datazoom sont synchronisés.

groupSync

Survolez une catégorie ou utilisez les contrôles de zoom : les deux instances utilisent le même groupe.

Code minimal
const syncOptions = {
  tooltip: { shared: true, intersect: false },
  chart: { zoom: { enabled: true, type: 'x' } },
};

<chart [config]="lineConfig" [data]="rows"
  group="sales-dashboard" groupSync="all"></chart>
<chart [config]="areaConfig" [data]="rows"
  group="sales-dashboard" groupSync="all"></chart>

WRAPPER

Toolbar et navigation de type

showToolbar affiche la toolbar ApexCharts et les commandes de navigation du wrapper. Le pivot reste désactivé dans cette démonstration et ne doit être activé que lorsqu’il est réellement utilisé.

showToolbar
Code minimal
const config = {
  showToolbar: true,
  series: [{ data: { x: field('day'), y: field('count') } }],
};
