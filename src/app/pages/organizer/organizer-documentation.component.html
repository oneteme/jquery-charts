jquery-organizer / exemples

Donner une vue claire aux choix de l’utilisateur.

Le bouton Organizer expose les choix pertinents et renvoie un état. Chaque carte montre ensuite comment une vue hôte peut utiliser cet état.

Consulter la référence API ↗
Déclarer Exposez seulement les champs, axes, groupes et filtres utiles à votre écran.
Écouter viewChange renvoie un état complet après chaque choix utilisateur.
Appliquer Le parent garde la main sur le graphique, le tableau ou toute autre vue métier.
Composer Les templates regroupent plusieurs choix dans une vue immédiatement exploitable.
