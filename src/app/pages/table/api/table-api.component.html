LAZY + API PUBLIQUE

Colonnes lazy et requête relancée

Une colonne lazy est forcément optionnelle : optional: true est implicite et optional: false lève une erreur. Ouvrez le menu View et ajoutez Capitale, Devise ou Langues (ou groupez par Devise) : la table appelle le lazyLoader de la config, qui relance la requête GraphQL de l’API publique countries.trevorblades.com avec ces champs ; les nouvelles lignes remplacent les anciennes.
