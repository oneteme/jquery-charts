jquery-table / slice + graphique

Un filtre de table qui pilote un graphique.

<slice-panel> est indépendant de <jquery-table> : l’hôte reçoit un prédicat, recalcule ses données et les transmet au renderer de son choix.

Consulter la référence API ↗

3 · Recalculer Le composant hôte agrège les lignes filtrées par développeur.
4 · Afficher Le graphique reçoit seulement chartData, sans connaître le panneau.
